# LiHui International Logistics — lihui-cargo.ru

Статический сайт (без сборщиков, без внешних зависимостей и CDN) о закупке и
доставке из Китая в Россию, Беларусь, Казахстан и Кыргызстан.

## Что на сайте

| Страница | Файл | Назначение |
| --- | --- | --- |
| Главная | `index.html` | услуги, процесс, маршруты, калькулятор, примеры расчётов, FAQ, форма заявки |
| Услуги | `services.html` | шесть этапов поставки, порядок работы, ограничения по грузам |
| Маршруты | `routes.html` | таблицы сроков по городам, сравнение авиа и наземной доставки |
| Калькулятор | `calculator.html` | объём, объёмный и оплачиваемый вес, отправка расчёта менеджеру |
| О компании | `about.html` | подход, принципы, география, контакт руководителя |
| Вопросы | `faq.html` | 12 вопросов с разметкой FAQPage для поиска |
| Контакты | `contacts.html` | Telegram, WhatsApp, телефон, QR-коды, форма, проверка статуса |
| Документы | `privacy.html`, `terms.html` | политика конфиденциальности и условия обслуживания |
| Ошибка | `404.html` | страница «не найдено» для GitHub Pages |

Технически: `/robots.txt`, `/sitemap.xml`, `site.webmanifest`, `CNAME`
(`lihui-cargo.ru`), `.nojekyll`.

## Функции

- Три языка: русский (по умолчанию в HTML), английский, китайский. Переключатель
  в шапке и в мобильном меню, выбор запоминается; поддерживается `?lang=zh`.
  Язык браузера определяется автоматически только при первом визите.
- Калькулятор веса: объём, объёмный вес (÷6000), оплачиваемый вес, кнопка
  «Сохранить расчёт в PDF» (через печать браузера).
- Формы-заявки: не отправляют данные на сервер, а открывают Telegram или
  WhatsApp с готовым сообщением (текст зависит от языка страницы).
- Проверка статуса груза: сообщение с номером отправления уходит менеджеру.
- Быстрые контакты: плавающие кнопки WhatsApp/Telegram, мобильная нижняя панель,
  клик по телефону, QR-коды в разделе контактов.
- Избранное и «поделиться» (Web Share API, ссылки в мессенджеры, копирование).
- Мягкие анимации появления, индикатор прокрутки, адаптивность, поддержка
  `prefers-reduced-motion`, доступность с клавиатуры и скринридера.
- `window.dataLayer` получает события (`lh_page_view`, `lh_calc_submit`,
  `lh_contact_click`, `lh_lang_change`, `lh_share`, `lh_favorite`) — можно
  подключить любую аналитику без правки вёрстки.

## Структура

```
index.html … 404.html      готовые страницы (то, что отдаёт GitHub Pages)
assets/css/styles.css      единая таблица стилей
assets/js/site.js          вся логика: языки, калькулятор, формы, эффекты
assets/js/i18n.js          словари ru/en/zh и конфиг (ГЕНЕРИРУЕТСЯ)
assets/img/                hero.jpg, ceo.jpg, qr-telegram.png, qr-whatsapp.png
assets/brand/favicon.svg   иконка сайта
src/                       исходники CSS/JS/иконки
tools/                     генератор страниц и данные
```

## Как менять контент

Тексты, телефоны, маршруты и таблица сроков лежат отдельно от вёрстки:

- `tools/i18n.ru.mjs`, `tools/i18n.en.mjs`, `tools/i18n.zh.mjs` — тексты
  (во всех трёх файлах одинаковый набор ключей, иначе сборка упадёт с ошибкой);
- `tools/site.data.mjs` — бренд, контакты, маршруты и сроки, города, площадки,
  примеры расчётов, тарифы.

После правок нужно пересобрать сайт:

```bash
node tools/build.mjs
```

Сборка проверяет, что ключи трёх языков совпадают, и обновляет HTML-страницы,
`sitemap.xml`, `robots.txt`, `site.webmanifest` и `assets/js/i18n.js`.

## Тарифы в калькуляторе

По умолчанию калькулятор считает вес и объём, а стоимость подтверждает
менеджер. Чтобы показывать диапазон цены, откройте `tools/site.data.mjs`:

```js
export const PRICING = {
  enabled: true,
  currency: 'RUB',
  rates: {
    'moscow:air': { min: 0, max: 0 },   // цена за кг
    'moscow:ground': { min: 0, max: 0 },
    'almaty:air': { min: 0, max: 0 },
  },
};
```

Ключ — `город:способ` (`air` или `ground`). После заполнения пересоберите сайт.

## Публикация

Сайт размещён на GitHub Pages из ветки `main` репозитория `1114536579a-cloud/lh`.
Домен `lihui-cargo.ru` задаётся файлом `CNAME`. Достаточно закоммитить изменения
и запушить в `main` — сборка и публикация происходят автоматически.
